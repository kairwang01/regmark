# Code of conduct

Regmark is a small project. Most of the work here is people checking each
other's code and claims. Keep that civil and useful.

- Be civil. Assume the person who wrote a report or a patch is trying to get
  something right.
- Criticise code and claims, not people. "This rule fires when the page shows a
  sale" is useful. Remarks about a person's ability are not.
- No harassment and no personal attacks, in issues, pull requests, reviews or
  anywhere else in the project.
- Do not publish other people's private information, including a shop's staff
  or customers, in an issue or a pull request.
- A report that a rule is wrong is welcome. It is a contribution, not a
  complaint.
- Maintainers may remove comments, close issues or pull requests, or block
  accounts that make the project hard to work on. They will say why where they
  can.

To raise a concern about how someone in the project behaved, contact the
maintainer, Kair Wang, through the email address on the GitHub profile at
https://github.com/kairwang01.
